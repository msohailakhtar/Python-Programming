COURSE OVERVIEW

Course Description

Python Programming introduces students to the fundamental concepts of programming using the Python language. The course develops computational thinking, problem-solving skills and programming practices required for modern mathematics, data science, artificial intelligence and machine learning.

Topics include variables, data types, operators, input and output, conditional statements, loops, functions, data structures, file handling, object-oriented programming and introductory scientific computing with Python.
